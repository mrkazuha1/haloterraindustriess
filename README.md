# HALO TERRA INDUSTRIES — сайт сервера

Сайт написан на чистом Node.js без внешних зависимостей. `npm install` не нужен.

## Запуск

Нужен Node.js 18 или новее.

```
node server.js
```

Откройте http://localhost:3000

Другой порт: `PORT=8080 node server.js`

## Короткий адрес на своём компьютере

Адрес вида `Haloterraindustries.3000` сделать нельзя: `3000` — это номер порта, а доменные зоны состоят из букв. Короткое имя можно задать только для вашего компьютера. Откройте Блокнот от имени администратора, откройте файл `C:\Windows\System32\drivers\etc\hosts` и добавьте строку:

```
127.0.0.1 haloterraindustries
```

Сохраните файл, запустите сайт и откройте http://haloterraindustries:3000

Так сайт откроется только на этом компьютере. Чтобы он работал по настоящему адресу в интернете, нужен домен (например, `haloterraindustries.ru`) и хостинг, см. раздел «Размещение в интернете».

## Что умеет сайт

- **Новости.** Владелец публикует новость и прикрепляет до 5 фото. Фото уменьшаются в браузере, а на сервере проверяется, что файл действительно изображение. Удаление новости удаляет и её фото.
- **Лор.** Главная страница показывает краткий лор с кнопкой «Подробнее». Страница `lore.html` показывает подробный лор. Владелец редактирует её прямо на сайте: заголовок, вступление, разделы, порядок и удаление разделов. К каждому разделу можно прикрепить до 5 фото.
- **Игроки.** На главной показаны игроки с кратким описанием: оно появляется при наведении курсора на карточку. «Подробнее» открывает страницу `players.html`, где собраны все игроки. Список и описания владелец редактирует прямо на странице.
- **Скины игроков.** Владелец прикрепляет к игроку PNG-скин (64×64 или 64×32). На карточках показывается голова игрока.
- **Поддержка.** Кнопка «Поддержка» в шапке ведёт на `support.html`. Игрок входит в аккаунт и пишет обращение. Владелец видит все обращения, отвечает, закрывает и удаляет их. Есть быстрые ответы («Проверяем», «Решено», «Уточнить»). Список обновляется сам каждые 15 секунд.

## Что где лежит

- `server.js` — сервер: аккаунты, новости, лор, обращения, раздача файлов
- `public/index.html`, `public/lore.html`, `public/support.html` — страницы
- `public/style.css` — оформление
- `public/common.js` — печать текста, вход и регистрация, общие функции
- `public/app.js` — гимн и новости
- `public/lore.js` — подробный лор и редактор
- `public/support.js` — поддержка
- `public/players.js` — игроки сервера
- `public/assets/` — гимн (`anthem.mp3`) и эмблема (`logo.jpg`)
- `data/users.json` — аккаунты (пароли хранятся в виде хешей)
- `data/news.json` — новости
- `data/lore.json` — подробный лор
- `data/tickets.json` — обращения в поддержку
- `data/players.json` — игроки сервера
- `data/uploads/` — фото к новостям, фото лора и скины игроков

Папку `data/` не удаляйте: там аккаунты, новости, лор и обращения.

## Версия на GitHub Pages

Файлы из папки `public/` можно открыть с GitHub Pages, но вход, новости, лор, игроки и поддержка работают на сервере. Нужно:

1. Сервер с HTTPS, например VPS с Caddy из раздела «Размещение в интернете».
2. Разрешить адрес GitHub-версии на сервере. Скрипт `setup-vps.sh` спросит его сам. Вручную: `ALLOWED_ORIGIN=https://mrkazuha1.github.io PORT=3000 OWNER_PASSWORD="новый_пароль" pm2 start server.js --name halo`.
3. В файле `public/config.js` указать адрес сервера, например `window.HT_API_BASE = 'https://haloterraindustries.duckdns.org';`.
4. Загрузить содержимое папки `public/` в репозиторий GitHub Pages.

Вход может не работать в режиме инкогнито или в браузерах, которые блокируют cookie между сайтами.

## Размещение в интернете

Адрес `haloterraindustries.ru:3000` работает, если сайт запущен на сервере (VPS) с открытым портом 3000. На Render и Railway публичный порт нельзя задать вручную, а домашний компьютер не подходит: его IP меняется и он должен работать всё время. Статический хостинг (GitHub Pages) тоже не подойдёт: регистрация, новости, лор и поддержка работают через сервер.

Проще всего выполнить шаги ниже одной командой из папки сайта на сервере: `sudo bash deploy/setup-vps.sh`. Скрипт спросит пароль владельца и адрес сайта на GitHub (можно пропустить), поставит Node.js и pm2, запустит сайт и откроет порт. Ниже те же шаги вручную.

Шаги для VPS с Ubuntu:

1. Установите Node.js 18 или новее.
2. Скопируйте папку сайта на сервер вместе с `data/`, если переносите данные.
3. Смените пароль владельца: на публичном сервере не должен действовать пароль по умолчанию. Запустите сайт в фоне через pm2:

```
npm install -g pm2
PORT=3000 OWNER_PASSWORD="новый_пароль" pm2 start server.js --name halo
pm2 save
pm2 startup
```

Команда `pm2 startup` выведет строку, которую нужно выполнить. Она нужна, чтобы сайт поднимался после перезагрузки сервера.

4. Откройте порт 3000: `ufw allow 3000`.
5. В панели регистратора создайте A-запись: `haloterraindustries.ru` указывает на IP сервера. Обновление DNS может занять от нескольких минут до суток.

Сайт откроется по адресу http://haloterraindustries.ru:3000. Без HTTPS браузер покажет «Не защищено». Чтобы адрес был с https и без порта, нужен nginx на порту 443 и сертификат. Тогда `:3000` в адресе не нужен.
